Quick install steps

  1. Upload — Upload the ZIP to cPanel File Manager, extract to your domain folder.
  2. Set document root — Point to public/ (Layout A, recommended) or upload the whole project to public_html (Layout B).
  3. Permissions — Set storage/ and bootstrap/cache/ to 755 (or 775 if not writable).
  4. Database — Create a MySQL database + user with ALL PRIVILEGES in cPanel.
  5. Install — Open https://your-domain.com/install.php and follow the 5-step wizard.
  6. Delete installer — Remove public/install.php after installation.
  7. Cron — Add a cron job: /usr/local/bin/php /home/YOURUSER/pms/artisan schedule:run >> /dev/null 2>&1 (once per minute).
No Composer required. The build/vendor/ folder contains all dependencies. The app loads build/vendor/autoload.php directly — artisan, public/index.php and tests/bootstrap.php all reference it.
