Pair a tracking device

Works with any unit that can POST a position

In the real screen, pairing generates a 48-character token shown once; only its SHA-256 hash is stored. One device per car: a second unit is refused unless you tick the replacement box, because two trails on one vehicle would be added into a single distance figure. Buttons are disabled in this preview.
