What this sheet is. A property's configuration is not the settings somebody remembers changing: it is every value the property stores, every value it does not, and what the code does when nobody set one. This sheet states all of that as it stands at the print time above, so an auditor, an owner or an incoming manager can check it line by line instead of asking somebody.

The fingerprint. E41FFBA85AF0 is computed from all 612 settings and their stored values this minute. Print two sheets and compare the twelve characters: the same fingerprint means the same configuration, whatever else changed in the meantime. A credential contributes only whether one is stored — never its value — so the fingerprint cannot be used to guess one. The value trail on the last page says what moved since the sheet before it.
